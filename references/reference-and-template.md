# 参考拆解与模板规则

## 分开测量、解读与迁移

记录 `observed`（对象/原像测得）、`inferred`（人工判断职责）、`proposed`（适配自己内容）。颜色频次不能独自决定强调用途，字体资源名不证明本机安装或实际生效。

逐页文字用于还原论证；原像用于检查视线、层级、图文比例、局部强调和连接形态。不能用对象清单代替看页面。

## 已确认的页面组织

| 页面职责 | 应观察和迁移的关系 |
|---|---|
| 背景 | 实际场景/观测 → 数据或能力困难 → 需要什么能力 |
| 研究现状 | 代表主图 → 实际输入/计算/已核能力 → 当前任务下的可检验差异 |
| 目标与研究地图 | 能力要求、困难、设计与证据对应；支撑与并行各按事实画 |
| 机制 | 真实对象 → 表示 → 推理/计算 → 总体位置与局部展开 → 必要公式 |
| 结果 | 固定/改变条件 → 匹配样例/局部变化 → 总体量化 → 收益、代价与判断 |
| 总结/展望 | 已知结论与整体能力目标连接；当前重点、触发条件和未来设想分层 |

重点方法保留可读主图，不硬塞固定三列。总览只承担导航，技术细节在对应页展开。成熟成果范例可启发论证，不能把阶段负结果改成成功。

## 视觉语言

1. **局部强调：**关键词或决定判断的数字采用run级字重/颜色；大部分正文保持正常字重。整段同色同粗会消除焦点。
2. **框体层级：**外层页组/工作卡片、内部问题/设计框、计算节点、图签不同职责，不能全做同一矩形、字号与边框。
3. **连线：**细线用于实际信息/计算，展开线定位总体与局部，宽箭头承接论证，弯曲/汇聚说明多项设计服务目标，循环线表示真实反馈/演化。形态和语义一起验收。视觉汇聚不自动表示张量流。
4. **阅读路径：**对象、连线、标题和公式按讲述顺序相互定位；先看哪里、再看哪里必须能从成页辨认。
5. **图文比例：**削减重复解释，把空间还给主图；不靠缩字号获得信息密度。参考中的过密小图也需放大或分到备份。
6. **来源：**外部作者图/方法保留必要引用。内部索引、制图说明和授权提醒留制作日志，无引用的页不机械套引用底条。

## 历史参考中已确认的角色字体与视觉样式

这些是既有流程的起点，不是所有未来汇报的统一模板：

- 中文：Microsoft YaHei，常规/粗体分别核；英文和数字：Times New Roman；公式/希腊字母：按实际对象选择Cambria Math。
- 深蓝章节栏、黄字章节强调、白底正文；内层标题框与局部红字、浅底问题框和图签共同形成层级。
- 历史实现的角色色值包括蓝 `1954C9`、强调红 `BF2600`、黄 `FFF138`、正文 `151515`、灰 `657187`。它们是已用实现值，不冒称全部等于原稿精确测色。
- 16:9的历史成页为13⅓×7.5英寸；实际任务仍读取参考尺寸。原稿页眉/图标/底图属于参考资产，技能不附带，使用时需有素材与授权。

如用户明确指定继续某份稿，应保留其已确认shell和图式。不要把这条要求偷换成随包低层生成器的简化顶边/页脚外观。

## 字体核验

`check_fonts.py`核对macOS字体登记，可能受本地化family名影响；用别名核查，不因为英文精确匹配失败就认定未安装。应用私有/云字体另核。

按中文、拉丁、公式角色写入runs，不能全页统一替代。字体变更后重看字宽、行高、上下标与换行，系统登记、文件声明、Office实际显示分别记录。

## 封面与目录

按[封面目录规范](cover-and-navigation.md)单独处理。看完整参考的背景/主体构图、题名与副题、署名/机构/日期层级，不复制特定学校背景或他人身份；目录由实际主讲/备查章节和跳转目标生成，页面增删联动导航与引用。

已有工作流包含对应实践，未据此验证DSH/Codex或实际Office点击。此规范不改变正文机制图风格。

## 样页与整稿

存在重要风格分歧才校准代表页。校准应同时查看主图本身和嵌回页面后的缩放、标签、引导关系与比例。用户已经认可后，继续完整稿；不能把反复单页交付当成全稿进度。

Office预设形状也要看实际流向：历史 `curvedRightArrow` 显示为回钩，不适合预期汇聚。按已核曲线路径和标准箭头尖处理，或用明确合适的形态，不能因“原生对象”就判断视觉正确。
