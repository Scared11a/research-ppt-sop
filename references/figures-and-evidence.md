# 机制、图证与原生编辑层

## 从真实对象进入

输入是图像、掩码、特征、状态分布或样本对时，先展示它们实际长什么样、代表什么。缺少真实样例可画明确标为示意的对象；不能只写对象名称，也不能伪造采集/配准/实验图。

把每项设计讲清：输入输出、内部计算和作用位置、训练推理、设计理由、直接对照。必要公式靠近相应对象，符号与图一致；不只添加一个公式框。

## 逐边核对示例

下列是机制表达检查，不指定任何项目采用这些设计：

- 调制：主特征 `u → ×(1+γ) → +β → u′`；条件支路分别接到乘/加，γ与β不能误画成串行。
- 监督：真实目标或派生量进入损失；训练辅助头和推理主路径分开。stop-gradient、门限、归一化、加权范围按实际实现保留。
- 背景/关系：token源、query、访问mask、读取输出、融合与回写位置连续可追；不猜通道数或省略影响解释的中间量。
- 结构：幅度与布局各自进入其计算；构造训练样本和推理采样分区。独立/联合建模与固定样本集合后的重配是不同操作。
- 研究地图：连接表示数据供给、判断依据还是方法组合，写明。无已核接口/收益时不能以实线画成已成立系统。

## 外绘图与PPT文字共用一个坐标约定

已形成的制作路径是：独立SVG等机制源 → 确认图式与计算 → 将图形底层和文字层分离 → PPT整页编排 → 回读实际编辑对象。

自制标签、标题和公式变量要求原生可编辑时，采用以下已确认角色分工：

| 对象 | 最终承载 | 不能据此宣称什么 |
|---|---|---|
| 自制文字、符号、上下标 | PPT原生文字/runs，稳定名称 | 文字公式不是OMML原生Office公式 |
| 自制形状/线/路径 | 能可靠转换则DrawingML；或任务允许的无字图形底层 | 无字位图底层不是全图原生可编辑 |
| 实测图、照片、文献原图 | 保留真实图片及来源 | 不OCR“重建”数据，不以分辨率提升冒充新证据 |
| 图表数据 | 已有原生图表/工作簿尽量保留 | 自绘预览图不能证明原工作簿数据完整 |

从独立源迁入时保留完整SVG；同时确认底层确实不再含将由PPT显示的自制文字，避免重影。PPT中的文字应能单独定位；保留一张带字PNG并另附SVG不满足该要求。

### 手动/代码映射所需信息

设计源须记录 `viewBox=[vx,vy,vw,vh]`、文字锚点/字体/字号/颜色/runs、实际图件边界。PPT图位为英寸 `(x,y,w,h)`：

```text
k = min(w/vw, h/vh)
xx = x + (w - k*vw)/2
yy = y + (h - k*vh)/2
X = xx + (svgX-vx)*k
Y = yy + (svgY-vy)*k
font_pt = svg_font_size*k*72
```

原SVG y通常是文字基线，不可直接当PPT文本框顶端；按字体度量和实际设计预览校准。文字锚点start/middle/end分别对应左/中/右对齐。字体必须实际核验，PPT字号、留白和行高随最终放置比例复查。

历史转换器只支持受限矩形、圆、直线、多段线/多边形及 `M/L/H/V/Z` 路径，且不完整解析CSS、transform、滤镜和复杂marker。包内不提供一个冒称任意SVG转换的脚本。新图可以从同一设计源同时写出图形层与原生scene文字；若必须复用复杂SVG，先检查其语法，再只转换已覆盖的部分。未知部分暂停迁移，不静默丢弃。

若复用无字图形底层，源图保留、图内文字仍为原生；若用户还要求移动每条线和每个形状，须补足原生图形转换/重建与验证，不能降低要求。

## 图证的比较关系

- 样例告诉观众“差异在哪里”，总体统计告诉“所测范围内有多大”。两者不能相互替代。
- 对齐请求、背景、随机性、窗口/区域、reader版本与训练预算；改变多个因素的比较按配置级结果讲，不追加因果解释。
- 保留每个seed的真实结果；少量seed不包装成置信区间。覆盖代价、边界退化和失败例不缩成页脚。
- 改变窗口若同时改变可见背景，解释中保留这种耦合；全图读出和局部任务区分。
- 新读出复评与新增训练收益分开。跨任务、跨预算和跨读出绝对数值不能拼成一条进步曲线。
- “缺某个归因对照”不自动变成下一步训练安排；研究缺口与获准动作分别写。
