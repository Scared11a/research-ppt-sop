# 输入、工作文件与交接契约

## 先核哪些信息

| 字段 | 应从哪里取得 | 缺少时怎样处理 |
|---|---|---|
| 平台与能力/读写边界 | 实际host、工具表和版本，platform-contract工作副本 | 不假定Hana接口通用；缺能力只停对应步骤 |
| 封面信息与整页参考 | title/subtitle、署名/机构/会期、获准背景/标志、参考整页 | 缺身份不从他人模板补造，按cover-and-navigation处理 |
| 目录与导航 | 实际主讲/备查章节、页序、目标ID和引用映射 | 增删页同步范围/页码/跳转/正文备注引用 |
| 汇报用途/受众/能力目标/讨论目的 | 当前请求、主稿的汇报目的 | 影响整场组织且查不到时集中询问 |
| 时长/主讲与备份 | 已确认要求或现有完整稿 | 不用固定页数代替时长；无法排练就说明未估测 |
| 主稿及正式事实源 | 当前项目入口、状态文件/协议/日志 | 不把历史讨论或旧幻灯片当最新授权 |
| 当前完整稿/版本/源/manifest | 已交付清单、current入口、实际文件 | 核对脚本是否已被转发到增量入口 |
| 参考文件/代表页 | 当前附件、可访问PPTX/PDF | 用SessionFile身份解析，不猜缓存路径 |
| 图/表/CSV/样例身份 | 图证清单、真实产物、对应版本 | 缺来源或对应关系时只暂停相关结论 |
| 编辑要求 | 用户当前要求、已确认校准 | 记录文字、图形、图表数据、公式分别要求什么 |
| 字体/视觉规范 | 参考测量及已确认方案 | 缺字体先核验，替代需有依据与允许范围 |
| 输出/权限/负责写入者 | 当前委托及工作区规定 | 不安装、不外传、不实验、不改他人文件，除非另有授权 |

`assets/job-contract.json` 是填写骨架。复制到工作目录后填实值，保留 null 表示未知；它不是自动执行配置文件。新增字段分别指向`assets/platform-contract.json`、`assets/frontmatter-contract.json`及`assets/audience-review.csv`的工作副本。台账可以只指向受控来源，不要求复制资料。

封面/目录规范见[cover-and-navigation](cover-and-navigation.md)，平台能力见[platform-contract](platform-contract.md)，逐内容面的语义审阅见[audience-content](audience-content.md)。

## 图证台账

`assets/evidence-ledger.csv` 每行是一组有共同比较问题的图证，而不是每个小图一个研究主张。推荐状态词：

- `available_to_layout`：文件与必要身份已核，等待编排。
- `needs_verification`：已有材料，身份/版本/内容或解释仍待核。
- `needs_research`：需要尚未完成的研究证据；制图不等于执行授权。

保留总体/样例关系：样例选取规则、请求/背景/随机性、样本量与汇总层级、固定/改变条件。图片存在、CSV可读、原报告写“检查过”分别不足以证明结果可靠。

## 页面计划

每页/页组填：主稿位置、职责、本页问题、可支持判断、主图、总体统计、必要公式、训练/推理、前后转场、来源和缺口。封面、目录与备查分别标page_role；新增section_id/navigation_target/included_in_toc/audience_review_ref用于跟踪章节、导航与成品审阅，不把旧固定页码当实际顺序。复杂机制允许拆页，完整技术依据可进备份，不静默删除。

相关工作图位写成：`〔文献主图位：方法／版本／图号／比较焦点〕`。不仅写“放一张图”。缺图时先排出真实图格、标注/放大框及对照关系；占位不冒充结果。

## 新任务最少询问方式

先查已知资料，再只问影响方向的缺口。例如：
“当前主稿、参考和图表已齐；尚缺听众与时长，这会决定主讲/备份安排。请确认这两项。”

权限不明时只暂停受影响动作。不要因某张图暂不能从受限库导出，就停止已有文字/结构修改。

## 制作侧的文件角色

```text
work/
  job-contract.json           # 当前任务、权限与来源指向
  evidence-ledger.csv         # 图证状态，不竞争科研事实源
  page-plan.csv              # 主稿到页面及转场
  reference-inspection/      # 授权范围内的测量和代表页，不进skill包
  figures/                   # 本次设计源、图形层与图源记录
  scene.json                 # 本次低层页面对象；或现有项目构建源
  build/                     # 新版本，不覆盖原件
  audit/                     # 结构/内容/设计/Office各自结果
  delivery-report.md         # 实际交付与遗留
```

不强制已有项目重组为这个目录。复用其角色和入口即可。参考原件、科研正文和敏感数据不因封装流程就复制入技能。
