# Changelog

## 0.1.0 — 2026-10-28

First distributable repository release.

- Reference-driven core workflow for complete, editable research presentations.
- Shared capability contract with Hana, DeepSeek Harness/DSHana and Codex adapters.
- Cover, contents, page ranges, navigation and cross-page reference checks.
- Evidence/mechanism planning and audience-facing semantic review templates.
- Six existing local inventory, audit, font, scene and style helpers.
- Original icon/banner, host metadata, English/Chinese README and package checks.
- Private session identifiers, internal audit records and reference assets excluded.

Cross-platform PPT production, actual Office rendering and GUI editing are not release-tested capabilities.
